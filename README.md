#Student Event Registration Dashboard

#Overview
A responsive frontend web application built using HTML, Tailwind CSS, and Vanilla JavaScript
that allows users to manage student events. Users can add events, register or cancel registrations,
search events, and view live statistics. Data is stored using Local Storage, so it remains even after page refresh.
#Features
- Add new events dynamically  
- Register and cancel event participation  
- Real-time search functionality  
- Live statistics (total events, registered students, remaining seats)  
- Persistent data using Local Storage  

# Tools Used
- HTML5  
- Tailwind CSS  
- Vanilla JavaScript  
- Local Storage API
